# 名单 CSV 放这里

**这个目录下的 `*.csv` 不进版本库。** 它们含真实校友的姓名、性别与 UTR；
仓库里只允许出现虚构姓名（见 `openspec/config.yaml` 的校验规则）。

## 从组委会总表导出

总表是 Google Sheets。每个赛季组别的**赛前**名单 tab 导出为 CSV：
`文件 → 下载 → 逗号分隔值 (.csv)`，一次导出当前 tab。

赛后（After Event）tab 不导 —— 那是赛后复盘数据，人数与赛前名单也对不上。

## 期望的列

必需（缺任何一列，导入会直接失败而不是导出一份没有参赛 UTR 的名单）：

| 列 | 说明 |
|---|---|
| `Team` | 球队 code，原样存储，不拆联队成分 |
| `Last Name` / `First Name` | 按总表的两列拆分保存 |
| `DUTR Status` | 原样保存，含 `/ Appeal` 后缀 |
| `Match UTR` | 参赛 UTR，赛事实际采用的冻结值 |

可选：`Gender`、`Notes`（参赛 UTR 的来源依据，是判定评级类别的唯一凭据，
不要删这一列）。

取样窗口列按**前缀**识别（`Verified DUTR ...` / `DUTR ...`），日期逐年变化
无需改代码：2025 是 09/22–09/26，2026 是 09/21–09/25。

`Verified SUTR (Reference)` 与 `SUTR Status (Reference)` 会被忽略。
其余不认识的列会出现在导入报告里，不会被静默丢弃。

## 不来自 CSV 的字段

这三个由人工维护，导入器**不写也不清**：

- 外援标记 —— 总表无法识别外援
- UTR profile ID —— 总表没有这一列
- `Unrated` 行的评级类别 —— 取决于有无 USTA 比赛历史，总表不携带

重复导入不会覆盖它们。
