两个 change 归档（`2026-09-20-utr-import-mcp`、`2026-09-20-preset-name-prefill`），外加一个用户报的

### preset-name-prefill（载入回填名 + 「更新「X」」一键存回）
排阵页载入一套 preset 后名字框空着、想改约束存回同套要重打原名。改：`buildLoadHref` 多写 `preset=<名>`
参数，`Presets` 用 `useSearchParams` + 按参数值 keyed 的 effect seed 名字框；「存为阵型」按名是否命中已存
阵型切「更新「X」」（后端同名即更新）。保存仍读实时表单。两组 apply（g1 100、g2 98.4），真机 e2e：建阵型→
载入→名回填+按钮更新→改锁定→更新覆盖（DB 1 套不重复）。commit `5475b7e`。

### pin 载入 bug（用户报，线上纯 pin 阵「点载入没反应」）
根因：`buildLoadHref` 把 pin 写成 `pin=LINE:key`（后端搜索参数格式），但页面 `constraintsFromQuery` 只把
单座 `LINEa=key` 当 pin、忽略 `pin=` → 载入含 pin 的 preset 时 pin 被静默丢弃，纯 pin 阵载入无反应（lock
一直是单座写法所以没暴露）。修：pin 也写单座 `${line}a=key`。round-trip 单测 RED→GREEN，前端全套 627 +
tsc 0，真机建纯 pin 阵→载入→URL `D2a=...`（无 `pin=`）、下拉回填。commit `4a562b3`。已 sink 进
CLAUDE.md（「同一概念 URL 两种写法、读的一侧只认一种就静默丢」）。
