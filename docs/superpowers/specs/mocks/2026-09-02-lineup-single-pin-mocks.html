lineup-single-pin —— 视觉稿

一条线**只填一个座位 = pin**（把这个人钉在这条线，引擎配搭档、排满其余）；两个座位都填 = 现有**硬锁整对**；都不填 = 交给引擎。三种状态在控件里要一眼可分。pin 造成无解时，无解面板 点名被钉者与线、并在「含被钉者的对」里给原因。设计体系沿用 linear，不新增 token （pin 用 warning 档描边/角标，硬锁用 primary 档，无解面板复用 NoSolution 的 warning 档）。

桌面 · 控件里三种线状态

桌面 · pin 造成无解（诊断懂 pin）

被钉的人在这条线配不出合法搭档 → 无解面板点名 pin，并在「含被钉者的对」里给四类 原因之一（此处：都超搭档差距）。复用 NoSolution 的 warning 档。

凑不出合法阵容
在当前的锁定、pin 与排除下，混双（MD）没有任何合法搭档。
因为 pin 你把 Zhang Guang 钉在 MD，但在 MD 与他能配的女将里，每一对参赛 UTR 差距都超过上限 3.50——没有一对合法。
这不是「搜索没找到」——把 Zhang Guang 从 MD 松开，或换一个差距更近的搭档人选进名单。系统只据实读你当前的 pin/锁定/排除，不替你猜该换谁。

与无 pin 的无解面板同款样式；区别是原因**限定在「含被钉者的对」**里算，并**点名 被钉者 + 线**（因为 pin 前缀）。四类原因（人手/超cap/超差距/资格）复用 A 的 diagnose_line，只是多传一个 pin。

  • pin 造成无解：无解面板点名被钉者 + 线，原因限定在「含被钉者的对」里算，不给无关原因。
  • 桌面 + 375 都读得清、无横向溢出、对比度 ≥4.5:1（量 computed style）：warning #8a6508/#fbf5e6、primary #9c3417、中性 #6b665d。
