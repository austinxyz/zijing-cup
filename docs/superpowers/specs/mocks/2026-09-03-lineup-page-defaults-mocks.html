核对清单（实现后逐条量）

  • 有已存阵容且无 go：默认列出已存阵容、**不**跑候选（无候选请求）。
  • 点「搜索阵容」→ URL 带 go=1 + 控件参数 → 出候选；直访同一 URL 同结果。
  • 载入阵型 → 控件更新、URL 无 go、无候选；再点搜索才算。
  • 候选每格显示两人 姓名 + UTR + 性别；桌面 + 375 不横向溢出（表自带横滚）。
  • 就地输密码解锁 = 走登录 action、密码错同款反馈；解锁后写操作生效、写路由仍方法判权。
  • 对比度 ≥4.5:1、触摸目标 ≥44px（「搜索阵容」「载入」「解锁」均加大）。
