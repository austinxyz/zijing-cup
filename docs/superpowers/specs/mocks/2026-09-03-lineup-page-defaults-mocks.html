每条线 = 3 行（线头 + 两人各一行，♂蓝/♀粉）。候选**没算**（省冷启动整解）；要算点「搜索阵容」。 无已存阵容 = 空态 + 控件 + 同一按钮，也不自动搜。

② 载入阵型 = 填进现有排阵控件（可编辑，改后搜、也能存）

载入不是另开界面，是把该套锁定/排除**填进和常规排阵一样的控件**：每线一个下拉——选两人=锁定、选一人=pin 交给引擎配、都不选=整条交给引擎；外加「本场不能上」勾选。只是预填，随后可改、点搜索才算、也能存。

核对清单

  • 已存阵容 + 候选同款「每条线 3 行块」：行1 线名+和+buffer 占用；行2/3 每人一行 姓名+♂/♀+UTR。
  • ♂ 蓝 / ♀ 粉均 ≥4.5:1（量 computed style）；块头总和/超量对比达标。
  • 有已存阵容且无 go 不跑候选；点搜索加 go=1 才算；带 go 链接可分享直出。
  • 载入 → 可编辑控件 + 「搜索阵容/保存修改/另存」；保存不要求先搜。
  • 就地输密码解锁走登录 action；解锁后写生效、写路由仍方法判权。
  • 桌面两列块 / 375 单列，均不横向溢出；主操作 ≥44px。
