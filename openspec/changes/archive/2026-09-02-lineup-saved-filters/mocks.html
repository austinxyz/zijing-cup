lineup-saved-filters —— 视觉稿

给排阵控件加一块已存阵型（preset）：命名保存当前锁定/排除、列出、一键载入、删除。 设计体系沿用 linear，不新增 token。载入 = 把 preset 的锁定/排除写回 URL 参数， 搜索路径不变。管理限 admin（存/删），列出与载入任何人可用。锁定引用的人离队 → 载入面板明说 + 拒载；排除引用的人离队 → 照常载入（那条排除已无意义）。

preset 行：名 + 一眼看出规模（锁 N · 排 M）+ 载入（primary）+ 删除（danger，仅 admin）。 存行同名会覆盖，占位文字说清存的是「当前」锁定/排除。至少一条约束才可存。

载入失效（锁定引用的人已离队）

载入一个锁定指向已不在名单球员的 preset：不静默应用，明说 + 给删除/重建入口。沿用无解面板的 warning 档。

这个阵型已过期
「缺陈嘉禾备案」锁定的一名队员已不在当前名单，无法照它布阵。
D2 锁定的 韩雨萌 已不在名单（可能退赛或被移出）。这条锁没法应用，整套就不能保证还是你当初存的那套。
系统没有替你猜该换谁——只据实告诉你哪条锁失效了，怎么改由你定。

只有锁定失效才拒载。检查用页面已有的 search.roster 比对 preset 的 key，零额外请求。 文案不猜替补，交由用户——沿用「不拿看似健康的列表糊过去」纪律。

载入照常（只是排除引用的人已离队）

排除指向的人离队不算失效——排除一个上不了场的人本就是要的效果。照常载入，带一句中性提示。

核对清单（实现后逐条量）

  • preset 列表 per (赛季,组别,队)；admin 见存/删、非 admin 只见列出+载入。
  • 载入把 locks/excluded 写回 URL 参数，页面从 URL 重渲染，结果与手填一致。
  • 同名保存覆盖；至少一条约束才可存；名字转义、参数化入库。
  • 锁定引用离队球员 → warning 面板拒载 + 删除/重建；排除引用离队球员 → 中性提示照常载入。
  • 写路由无 admin 凭据被拒（方法判权）。桌面 + 375 对比度 ≥4.5（量 computed style）、无横向溢出。
