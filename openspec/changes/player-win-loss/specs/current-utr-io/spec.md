## ADDED Requirements

### Requirement: 导入读入胜/负两列写进队员战绩
CSV 导入 SHALL 识别当前 UTR 表末尾的 `胜`、`负`两列（在既有八列之后；表头名
`总场次,胜,负,胜率`），把它们写进队员的 `wins`/`losses`。`总场次` 与 `胜率` 是派生列，
SHALL 被忽略（不入库、不参与比对）。胜/负 SHALL 进导入的**预览 diff**（与 UTR 值一样，
写入前能看到改了什么、并计入字段计数，防止整列错位悄悄写入），并随既有的**全有或全无**
规则一起落库。

空单元格沿用既有「空格三义」约定：胜/负两格皆空 = 不动那名队员的战绩（不是清成 null）。
只带前八列的表（本系统自己导出的那套）导入时 SHALL 对战绩产生 0 处改动——没有胜/负列
就没有战绩改动，既有「原样导出原样导回 0 改动」的往返地基不受影响。

#### Scenario: 读到胜负并计一处改动
- **WHEN** 导入一行 `胜=67`、`负=20` 且该队员原值不同
- **THEN** 该队员 `wins`/`losses` 更新为 67/20，且在 diff 里各算一处字段改动

#### Scenario: 派生列被忽略
- **WHEN** 行里的 `总场次`/`胜率` 与 `胜+负`/算出的比例不一致
- **THEN** 以 `胜`/`负` 为准，`总场次`/`胜率` 不影响写入、不产生改动

#### Scenario: 没有胜负列的表不动战绩
- **WHEN** 导入只有前八列（无 `胜`/`负`）的表
- **THEN** 队员战绩不变，往返 0 改动的地基不受影响
